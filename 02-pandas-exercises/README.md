# Pandas Real-World Exercises — Practice Solutions

Verified, handwritten data-wrangling pipelines across real-world datasets.

### Topic Structure

- `01-filtering-and-sorting/`: Basic query filtering, boolean masking, and column sorting.
- `02-grouping/`: Split-apply-combine aggregation chains and conditional grouping.
- `03-merge-and-joins/`: Inner/outer joins, relational alignment, and dataset concatenation.
- `04-time-series/`: Datetime indexing, frequency resampling, and window operations.
- `05-stats-and-visualization/`: Distribution summaries and metric analysis.
