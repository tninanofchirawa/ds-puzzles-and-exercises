# Data Science Exercises & Puzzles Vault

An organized repository of verified, handwritten Python solutions across three canonical benchmark tracks:

---

### 1. [01-numpy-100](./01-numpy-100/)

- **Focus:** Array vectorization, memory strides, and linear algebra operations.
- **Reference:** Based on [rougier/numpy-100](https://github.com/rougier/numpy-100).
- **Target:** 100 exercises.

### 2. [02-pandas-exercises](./02-pandas-exercises/)

- **Focus:** Real-world data-wrangling pipelines, multi-dataset merges, and grouping logic.
- **Reference:** Based on [guipsamora/pandas_exercises](https://github.com/guipsamora/pandas_exercises).
- **Target:** Practical industry workflows.

### 3. [03-pandas-puzzles-100](./03-pandas-puzzles-100/)

- **Focus:** DataFrame edge cases, multi-indexes, and idiomatic query operations.
- **Reference:** Based on [ajcr/100-pandas-puzzles](https://github.com/ajcr/100-pandas-puzzles).
- **Target:** 100 logic puzzles.
