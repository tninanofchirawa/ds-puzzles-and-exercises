# 100 Pandas Puzzles — Practice Solutions

Verified, handwritten Python solutions for the 100 Pandas Puzzles challenge, testing idiomatic DataFrame mechanics and edge cases.

### Category Breakdown

- `01-dataframe-basics/`: Object creation, selections, column operations, and boolean masking.
- `02-data-cleaning/`: String operations, casting, invalid value filtering, and missing data imputation.
- `03-grouping-and-aggregation/`: Split-apply-combine logic, ranking, and cumulative sums.
- `04-multi-indexing-and-slicing/`: Hierarchical index slicing and cross-sections.
- `05-window-and-time/`: Datetime offsets, rolling windows, and shift computations.
