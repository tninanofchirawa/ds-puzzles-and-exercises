# 100 NumPy Exercises — Handwritten Solutions

A structured repository of verified, handwritten Python solutions for the canonical 100 NumPy exercises.

### Directory Structure
- `01-vectors-and-matrices/`: Vector initialization, null vectors, indexing, and slicing.
- `02-array-manipulation/`: Reshaping, broadcasting, transposition, and stride slicing.
- `03-linear-algebra-and-ops/`: Dot products, matrix decompositions, and vector operations.
- `04-advanced-and-miscellaneous/`: Memory layouts, structured arrays, and ufuncs.
